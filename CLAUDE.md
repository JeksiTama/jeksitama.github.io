# PlayTama site

Static GitHub Pages site (no build). Home page = `index.html` + `assets/js/home.js`; games grid data in `assets/js/games.js`; shared save in `assets/js/tama.js`; shared game pieces in `assets/js/tama-kit.js`.

- The site's rules live in `docs/SITE_RULES.md`. Follow them for any game or site work, and update that file in the same change when a rule changes.
- Working on one game? Read only `docs/SITE_RULES.md` and the game's own folder under `games/`.
- The site file is the main version of each game. A prototype is a side branch for testing mechanic changes (Main Jempol's is `D:\Game Projects\main_jempol\prototype\jempol_hands.html`). Don't copy between a prototype and the site unless asked.
- Never use "coming soon". Use neutral wording.
- Audience is families with kids: no trackers, ads, accounts or personal data.
- The owner commits changes themselves. Don't commit, and don't ask or offer to commit.
