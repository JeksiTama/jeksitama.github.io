Tama Tokens

Tama Tokens are PlayTama's coins, shared by every game on this site.

  • You start with 20.
  • Open a game from the games page to get +1. Each game gives one a day.
  • In Main Jempol, every match costs 2 tokens to join, and the winners take the pot.

Tama Pass

Your tokens and scores are saved in this browser. The Tama Pass is a short code that holds them, a bit like a cheat code from old consoles.

  • Tap your token count at the top of any page to see your code.
  • Write it down to keep your progress safe.
  • On a new phone or computer, enter the code in the same place to pick up where you left off.
